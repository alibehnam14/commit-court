# ⚖️ دادگاه کامیت (commit-court)

**تاریخچه‌ی گیت خود را به دادگاه بکشانید.**

با یک دستور، هر مخزن گیت به یک پرونده‌ی جنایی نوآر تبدیل می‌شود: فایل‌های متهم، مجرمان
سابقه‌دار، جرم‌های ساعت سه بامداد، و یک رأی نهایی همراه با حکم.

</div>

```bash
pipx install git+https://github.com/your-username/commit-court.git
commit-court . --lang fa
```

<div dir="rtl">

خروجی یک فایل HTML مستقل به نام `commit-court-report.html` است که بدون اینترنت باز می‌شود.
نمونه: [`examples/sample-report.fa.html`](examples/sample-report.fa.html)

## بخش‌های پرونده

- **سربرگ پرونده:** نام مخزن، بازه‌ی زمانی، تعداد کامیت‌ها و مشارکت‌کنندگان، شماره‌ی پرونده
- **متهمان:** ده فایلی که بیشترین کامیت رفع باگ را داشته‌اند
- **مجرمان سابقه‌دار:** بدترین پیام‌های کامیت مثل `fix`، `asdf`، `wip` و `final_final2`
- **زمان وقوع جرم:** نمودار ساعتی و روزانه، و ساعت اوج کامیت‌های بد
- **رکوردها:** طولانی‌ترین روزهای پیاپی کامیت و طولانی‌ترین سکوت
- **کانون‌های پرتغییر:** پرتغییرترین فایل‌ها
- **رأی دادگاه:** نمره‌ی سلامت ۰ تا ۱۰۰، رأی طنز و حکم، و دکمه‌ی کپی متن اشتراک‌گذاری

## حریم خصوصی

- این ابزار به‌طور پیش‌فرض هیچ چیزی را آپلود نمی‌کند و کاملاً آفلاین کار می‌کند.
- رأی هوش مصنوعی فقط با پرچم `--ai` و تنظیم `ANTHROPIC_API_KEY` فعال می‌شود.
- در آن حالت فقط آمار تجمیعی و حداکثر ۱۰ پیام کامیت ارسال می‌شود؛ هرگز کد، diff، مسیر فایل یا نام افراد ارسال نمی‌شود.

## فرمول نمره

</div>

```
score = round(100 − 35·B − 25·F − 20·H − 20·L)
```

<div dir="rtl">

- **B:** نسبت پیام‌های بد
- **F:** نسبت کامیت‌های رفع باگ (تا ۱۵٪ سالم است)
- **H:** تمرکز تغییرات در شلوغ‌ترین ده درصد فایل‌ها
- **L:** نسبت کامیت‌های نیمه‌شب (۲۳ تا ۵ صبح)

جزئیات کامل در [README انگلیسی](README.md#score-formula).
